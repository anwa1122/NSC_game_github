# From Zero (เริ่มจากศูนย์)

เกมเพื่อการเรียนรู้ที่พัฒนาขึ้นเพื่อเข้าร่วมการแข่งขัน **NSC ครั้งที่ 28**
ภายใต้หัวข้อ **นวัตกรรมเพื่อความยั่งยืน**

From Zero นำเสนอการเรียนรู้ผ่านรูปแบบเกม โดยผสมผสานการคัดแยกขยะ
การเขียนโปรแกรม และระบบการเล่นเข้าด้วยกัน เพื่อให้ผู้เล่นได้เรียนรู้ผ่านการลงมือทำ

## 👨‍💻 บทบาทและหน้าที่

**Programmer**
- ออกแบบและพัฒนาระบบของเกม (Game System)
- เขียน Game Logic
- พัฒนาระบบ Quest และ Mini-games
- มีส่วนร่วมในการออกแบบระบบและการทำงานของเกม

**Team Collaboration**
- ทำงานร่วมกับสมาชิกฝ่ายโมเดล
- ใช้ GitHub Desktop ในการจัดการและแลกเปลี่ยนไฟล์ของโปรเจกต์

## 🛠️ Tools & Technologies

- Unity Engine
- C#
- ShaderLab
- HLSL
- GitHub Desktop

## 🏆 Competition

**National Software Contest (NSC) ครั้งที่ 28**

หัวข้อ: **นวัตกรรมเพื่อความยั่งยืน**

ประเภท: **โปรแกรมเพื่อความบันเทิง**

> ผลงานไม่ผ่านการคัดเลือกในรอบถัดไป แต่ได้รับข้อเสนอแนะจากคณะกรรมการ
> ซึ่งนำมาใช้เป็นแนวทางในการปรับปรุงและพัฒนาผลงานต่อไป

## 📚 สิ่งที่ได้รับจากการพัฒนา

การพัฒนา From Zero ทำให้ได้เรียนรู้ทั้งด้านการพัฒนาเกม
การทำงานร่วมกับผู้อื่นผ่านระบบจัดการไฟล์ และการนำข้อผิดพลาด
รวมถึงข้อเสนอแนะจากการประเมินมาปรับปรุงการทำงาน

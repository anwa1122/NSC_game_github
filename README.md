# From Zero (เริ่มจากศูนย์)

โปรเจกต์เกมที่พัฒนาส่งเข้าแข่งขัน NSC ครั้งที่ 28 ในหัวข้อนวัตกรรมเพื่อความยั่งยืน (รับหน้าที่ Programmer เขียนโค้ดและวางระบบอย่างเดียวครับ เรื่องโมเดล ภาพ และแสงสีเพื่อนในทีมเป็นคนจัดการ)

## บทบาทหน้าที่
- **Programmer:** ออกแบบระบบเกม (Game System), เขียน Game Logic, ระบบ Quest, UI และ Mini-games
- **Team Collaboration:** ใช้ GitHub Desktop ในการจัดการไฟล์ ทำงานร่วมกับฝ่ายโมเดล

## Tools
- Unity Engine (C#, ShaderLab, HLSL)
- GitHub Desktop
